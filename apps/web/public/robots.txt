# Kaffeelisten is a campus kiosk, not a website.
#
# Every deployment of this app - the demo and any campus instance - serves the
# same single-page application, which answers 200 for every path because of the
# SPA rewrite in vercel.json. Without this file a crawler finds an unlimited
# number of distinct URLs all returning identical HTML, under a hostname
# carrying the same brand name as kaffeelisten.de. That competes with the
# landing page and wastes crawl budget on a page nobody searches for.
#
# The header X-Robots-Tag: noindex, nofollow in vercel.json covers the same
# ground for paths this file cannot reach, and for URLs already indexed.
#
# kaffeelisten.de is the page meant to be found. It has its own robots.txt and
# sitemap in the kaffeelisten.github.io repository.

User-agent: *
Disallow: /
